# 1.4 Постановка задачи

## Проблема

Компания PBS не имеет современного веб-приложения, которое позволяло бы:

- Клиентам — ознакомиться с услугами, оставить заявку и отслеживать её статус
- Сотрудникам — управлять заявками, менять статусы, вести историю работы

Текущий сайт-визитка не решает этих задач, а учёт в Google Sheets неудобен и не даёт клиентам прозрачности.

## Цель проекта

Разработка одностраничного веб-приложения (SPA), включающего:

1. **Лендинг** с информацией о компании и форме заказа
2. **Личный кабинет клиента** для отслеживания заказов
3. **CRM-панель сотрудника** для управления всеми заявками

## Границы проекта (Scope)

### Входит в scope

- Разработка frontend-приложения на React + MUI
- Реализация лендинга (Hero, Услуги, О компании, Контакты)
- Форма заказа мероприятия с современным UX (визуальный выбор типа, слайдер гостей)
- Личный кабинет клиента с авторизацией по имени/email
- CRM-панель сотрудника со статистикой и управлением заказами
- Хранение данных в localStorage (демо-режим, без серверной части)
- Публикация на Vercel
- Документирование в формате отчёта

### Не входит в scope (перспектива)

- Backend-сервер и база данных
- Онлайн-оплата
- Email- и Telegram-уведомления
- Интеграция с внешними календарями
- Мобильное приложение

## Критерии успеха

1. Пользователь может оставить заявку через лендинг — заявка появляется в CRM
2. Сотрудник может изменить статус заказа и написать комментарий
3. Клиент видит актуальный статус и комментарии в своём ЛК
4. Приложение адаптировано под мобильные устройства
5. Сборка проходит без ошибок, проект опубликован на Vercel
