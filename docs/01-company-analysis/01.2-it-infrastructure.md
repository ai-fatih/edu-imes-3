# 1.2 Обзор ИТ-инфраструктуры компании

## Текущее состояние

На момент начала практики компания PBS использовала:

- **Сайт-визитка** на устаревшем HTML+CSS (только информация, без функционала заказа)
- **Учёт заказов** — в Google Sheets (менеджеры вручную вносили данные)
- **Коммуникация** — телефон, email, мессенджеры
- **Хостинг** — shared-хостинг без SSL

## Выявленные проблемы

1. Отсутствие единой системы учёта заказов
2. Невозможность для клиента отследить статус своего заказа
3. Ручное формирование отчётов
4. Нет личного кабинета для клиентов
5. Сотрудники не имеют инструмента для CRM

## Целевая архитектура проекта

Проект представляет собой Single Page Application (SPA) на современном стеке:

```
┌─────────────────────────────────────────┐
│              Browser (SPA)               │
├─────────────────────────────────────────┤
│  React 19 + Vite 8 + MUI 9 + React Router 7  │
├─────────────────────────────────────────┤
│     localStorage (персистентность)       │
└─────────────────────────────────────────┘
```

## Выбранный стек технологий

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| Фреймворк | React 19 | Построение пользовательских интерфейсов |
| Сборщик | Vite 8 | Быстрая сборка и HMR |
| UI-библиотека | MUI 9 (Material UI) | Готовые компоненты, темизация, сетка |
| CSS-движок | Emotion 11 | CSS-in-JS стилизация |
| Роутинг | React Router 7 | Навигация между страницами |
| Состояние | React Context + useReducer | Управление данными заказов |
| Персистентность | localStorage | Хранение данных на клиенте |
| Иконки | MUI Icons | Набор иконок Material Design |
| Шрифт | Google Fonts (Inter) | Основной шрифт |
| Деплой | Vercel | Публикация и хостинг |
| Версионирование | Git + GitHub | Контроль версий |

## Инструменты разработки

- **Среда разработки:** VS Code
- **Менеджер пакетов:** npm
- **Линтер:** ESLint с react-hooks и react-refresh
- **Прототипирование:** Figma
