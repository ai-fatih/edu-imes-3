# 2.3 Моделирование данных

## Выбор подхода

В связи с отсутствием серверной части и базы данных на этапе демо-версии, данные хранятся в **localStorage** браузера. Однако логически данные организованы как в документо-ориентированной БД (JSON-документы).

## Сущности

### Order (Заказ)

Основная сущность системы.

```json
{
  "id": "ORD-001",
  "clientName": "Иван Петров",
  "clientPhone": "+7 (916) 555-12-34",
  "clientEmail": "ivan@example.com",
  "eventType": "Свадьба",
  "eventDate": "22.06.2026",
  "guests": 80,
  "message": "Хотим свадьбу на 80 человек в загородном стиле",
  "status": "in_progress",
  "createdAt": "2026-05-10T10:30:00.000Z",
  "comments": [
    {
      "id": "c1",
      "text": "Заявка принята. Подбираем площадки.",
      "author": "employee",
      "authorName": "Анна Менеджер",
      "createdAt": "2026-05-10T11:00:00.000Z"
    }
  ],
  "employeeNotes": "Клиент хочет шатер или банкетный зал."
}
```

#### Поля

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `string` | Уникальный идентификатор (ORD-001, ORD-002...) |
| `clientName` | `string` | Имя клиента |
| `clientPhone` | `string` | Контактный телефон |
| `clientEmail` | `string` | Email клиента |
| `eventType` | `string` | Тип мероприятия |
| `eventDate` | `string` | Дата мероприятия (DD.MM.YYYY) |
| `guests` | `number` | Количество гостей |
| `message` | `string` | Пожелания клиента |
| `status` | `string` | Статус заказа (enum) |
| `createdAt` | `string` | Дата создания (ISO 8601) |
| `comments` | `Comment[]` | Массив комментариев |
| `employeeNotes` | `string` | Внутренние заметки сотрудника |

#### Статусы (enum)

| Значение | Метка | Цвет |
|----------|-------|------|
| `new` | Новая | info |
| `confirmed` | Подтверждена | primary |
| `in_progress` | В работе | warning |
| `completed` | Выполнена | success |
| `cancelled` | Отменена | error |

### Comment (Комментарий)

Вложенная сущность в составе Order.

```json
{
  "id": "c1",
  "text": "Заявка принята. Подбираем площадки.",
  "author": "employee",
  "authorName": "Анна Менеджер",
  "createdAt": "2026-05-10T11:00:00.000Z"
}
```

#### Поля

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `string` | Уникальный идентификатор (c1, c2...) |
| `text` | `string` | Текст комментария |
| `author` | `string` | Тип автора: `employee`, `client`, `system` |
| `authorName` | `string` | Отображаемое имя автора |
| `createdAt` | `string` | Дата создания (ISO 8601) |

## Связи сущностей

```
Order 1 ──── * Comment
  │
  └─── clientEmail связывает с пользователем
```

## Схема данных в localStorage

```
Ключ: "pbs_orders"
Значение: Order[] (JSON-массив)
```

## Реализация в коде

Хранение и управление данными реализовано в файле `src/store/AppContext.jsx`:

- **Контекст:** React Context (`AppProvider`)
- **Редьюсер:** `useReducer` с actions: `ADD_ORDER`, `UPDATE_STATUS`, `ADD_COMMENT`, `UPDATE_NOTES`
- **Персистентность:** `useEffect` синхронизирует состояние с `localStorage`
- **Инициализация:** при отсутствии данных в localStorage загружаются 5 предзаполненных заказов (sampleOrders)
