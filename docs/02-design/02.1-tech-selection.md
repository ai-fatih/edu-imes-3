# 2.1 Выбор технологий

## Критерии выбора

При выборе технологического стека учитывались следующие критерии:

1. **Современность** — технологии должны быть актуальны на 2025–2026 гг.
2. **Производительность** — быстрая загрузка, плавный интерфейс
3. **Экосистема** — наличие готовых компонентов, документации, сообщества
4. **Опыт команды** — технологии, доступные для изучения студентами
5. **Масштабируемость** — возможность дальнейшего расширения

## Сравнение и обоснование

### Фреймворк: React 19 vs Vue 3 vs Angular

| Критерий | React 19 | Vue 3 | Angular |
|----------|----------|-------|---------|
| Порог входа | Средний | Низкий | Высокий |
| Гибкость | Высокая | Высокая | Низкая |
| Экосистема | Огромная | Большая | Большая |
| Производительность | Высокая | Высокая | Средняя |
| Востребованность на рынке | Очень высокая | Средняя | Средняя |

**Выбор: React 19** — наибольшая востребованность, огромная экосистема, компонентный подход, Virtual DOM.

### Сборщик: Vite 8 vs Webpack

| Критерий | Vite 8 | Webpack 5 |
|----------|--------|-----------|
| Скорость HMR | Мгновенная (<50ms) | Заметная (>200ms) |
| Скорость сборки | 1-2 сек | 5-10 сек |
| Конфигурация | Минимальная | Сложная |
| Поддержка React | Нативная | Через плагины |

**Выбор: Vite 8** — значительно быстрее Webpack, простая конфигурация, современный подход (ESM в dev-режиме).

### UI-библиотека: MUI 9 vs Ant Design vs Tailwind

| Критерий | MUI 9 | Ant Design | Tailwind CSS |
|----------|-------|-----------|-------------|
| Готовые компоненты | 50+ | 60+ | Нет (утилиты) |
| Темизация | Мощная (ThemeProvider) | CSS-переменные | tailwind.config |
| Адаптивность | Grid + sx | Grid | Встроенная |
| CSS-движок | Emotion (CSS-in-JS) | Less | PostCSS |
| Размер бандла | Средний | Крупный | Минимальный |

**Выбор: MUI 9** — богатый набор готовых компонентов, мощная темизация, встроенная адаптивность, поддержка SSR и a11y.

### Роутинг: React Router 7

React Router — стандарт де-факто для навигации в React-приложениях. Версия 7 предлагает:
- Декларативные маршруты
- URL-параметры (useSearchParams)
- Вложенные маршруты (layouts)
- Поддержка SSR

### Состояние: React Context + useReducer

Для демо-приложения без серверной части не требуется Redux или Zustand. Встроенный Context API + useReducer обеспечивают:
- Глобальное состояние, доступное из любого компонента
- Предсказуемые изменения через reducer
- Нулевые дополнительные зависимости

### Персистентность: localStorage

Данные сохраняются в localStorage браузера — простое и надёжное решение для демо-версии:
- Не требует сервера
- Данные не теряются при обновлении страницы
- JSON-формат для сериализации заказов

## Почему не TypeScript?

На данном этапе проект реализован на JavaScript (JSX) для ускорения разработки. TypeScript рекомендуется добавить на следующем этапе развития проекта для повышения надёжности и улучшения DX.
