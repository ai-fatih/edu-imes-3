# 3.4 Публикация на Vercel

## Выбор платформы

Vercel выбран по следующим причинам:

- Бесплатный тариф для личных проектов
- Автоматический деплой из GitHub
- Поддержка SPA (настройка fallback для роутинга)
- HTTPS по умолчанию
- Быстрая CDN-доставка
- Простая конфигурация (Zero Config)

## Процесс деплоя

### 1. Подготовка репозитория

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/ai-fatih/edu-imes-3.git
git push -u origin master
```

### 2. Подключение к Vercel

1. Войти в Vercel через GitHub
2. Нажать "Add New Project"
3. Выбрать репозиторий `edu-imes-3`
4. Vercel автоматически определяет Vite-проект
5. Настройки по умолчанию:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
6. Нажать "Deploy"

### 3. Настройка SPA-роутинга

Для корректной работы React Router на Vercel необходимо добавить файл `vercel.json` в корень проекта:

```json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

Это перенаправляет все запросы на `index.html`, позволяя React Router обрабатывать маршруты на стороне клиента.

### 4. Автоматический деплой

После настройки Vercel автоматически деплоит каждое изменение в ветке `master`:

```
git push → GitHub → Vercel Webhook → Build → Deploy → 🔗 probanquet.vercel.app
```

## Конфигурация Vite

**Файл:** `vite.config.js`

```js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
})
```

Минимальная конфигурация — Vercel использует настройки Vite по умолчанию.

## Результат деплоя

После деплоя доступны:

| Ресурс | URL |
|--------|-----|
| Сайт | `https://edu-imes-3.vercel.app` |
| Репозиторий | `https://github.com/ai-fatih/edu-imes-3` |

### Проверка работоспособности

1. Открыть сайт — лендинг загружается
2. Проверить роутинг: `/login`, `/dashboard`, `/employee/dashboard`
3. Проверить 404: любой несуществующий путь
4. Проверить anchor-ссылки: `/#services`, `/#about`, `/#contact`
