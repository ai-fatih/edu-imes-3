# 3.3 Вёрстка и тема

## Тема MUI

**Файл:** `src/theme.js`

Тема приложения настроена через `createTheme` MUI и охватывает все визуальные аспекты.

### Цветовая палитра

Фирменные цвета компании PBS — тёмно-синий и золотой:

```js
primary:   { main: '#1a237e',  light: '#534bae',  dark: '#000051' }
secondary: { main: '#c6a862',  light: '#fada91',  dark: '#947935' }
background: { default: '#f8f9fa', paper: '#ffffff' }
text:       { primary: '#111827', secondary: '#6b7280' }
```

| Назначение | Цвет | HEX |
|-----------|------|-----|
| Основной (шапка, футер, акценты) | Тёмно-синий | `#1a237e` |
| Акцентный (CTA, иконки, ховеры) | Золотой | `#c6a862` |
| Фон страницы | Светло-серый | `#f8f9fa` |
| Карточки | Белый | `#ffffff` |
| Основной текст | Почти чёрный | `#111827` |
| Второстепенный текст | Серый | `#6b7280` |

### Типографика

Шрифт: **Inter** (Google Fonts) с запасными Roboto, Helvetica, sans-serif.

Используются `clamp()` для адаптивных размеров:

| Стиль | Вес | Размер | Строка |
|-------|-----|--------|--------|
| h1 | 800 | `clamp(2.2rem, 5vw, 3.8rem)` | 1.1 |
| h2 | 700 | `clamp(1.8rem, 4vw, 2.8rem)` | 1.2 |
| h3 | 600 | `clamp(1.4rem, 3vw, 2rem)` | 1.25 |
| h4 | 600 | `clamp(1.1rem, 2vw, 1.5rem)` | — |
| body1 | 400 | 1rem | 1.7 |
| body2 | 400 | 0.875rem | 1.6 |

### Тени

Кастомные многослойные тени для естественного объёма:

```js
// Тень 3-го уровня (карточки при hover)
'0 10px 25px rgba(0,0,0,0.06), 0 4px 10px rgba(0,0,0,0.03)'
```

### Скругления

- `shape.borderRadius: 12` — глобальный радиус
- `MuiCard: borderRadius: 16`
- `MuiButton: borderRadius: 10`

### Компонентные стили

**MuiButton:**
- Без `textTransform` (не ЗАГЛАВНЫЕ)
- Радиус 10px
- `contained`: тень `0 4px 14px rgba(26,35,126,0.25)` + hover с подъёмом
- `outlined`: hover с подъёмом

**MuiCard:**
- Радиус 16px
- Базовая тень + hover с усилением
- Плавный `transition: all 0.3s ease`

**MuiCssBaseline:**
- `scrollPaddingTop: 80px` (чтобы anchor-ссылки не перекрывались navbar)
- `scrollBehavior: smooth`
- `WebkitFontSmoothing: antialiased`
- `boxSizing: border-box` для всех элементов

## Адаптивная вёрстка

Адаптивность реализована тремя способами:

### 1. MUI Grid

Используется `Grid` с breakpoints для перестроения макета:

```jsx
<Grid item xs={12} md={7}>  {/* full width на мобильном, 7/12 на десктопе */}
<Grid item xs={12} sm={6} md={4}>  {/* 1/2 на планшете, 1/3 на десктопе */}
```

### 2. Responsive значения через sx

```jsx
sx={{
  py: { xs: 8, md: 12 },        // padding vertical
  fontSize: { xs: '2rem', md: '3.2rem' },  // адаптивный размер текста
  display: { xs: 'none', md: 'flex' },      // скрыть на мобильном
}}
```

### 3. clamp() в типографике

```css
fontSize: 'clamp(2.2rem, 5vw, 3.8rem)'
```

### Брейкпоинты

| Breakpoint | Ширина | Поведение |
|-----------|--------|-----------|
| xs | <600px | Мобильные (столбцы, скрытые элементы) |
| sm | 600–900px | Планшеты (2 колонки) |
| md | 900–1200px | Небольшие десктопы (3 колонки) |
| lg | >1200px | Десктопы (полная сетка) |

## Анимации и переходы

### Scroll-анимации

Для секций Services, About, Contact используется кастомный хук `useInView`:

```jsx
const [ref, inView] = useInView({ threshold: 0.15 })
// inView → CSS transition для opacity и translateY
```

### Hover-эффекты

- **Navbar:** прозрачный → белый с blur при скролле
- **Карточки услуг:** подъём -6px, усиление тени, подсветка иконки
- **Кнопки:** подъём -2px, усиление тени
- **Строки таблицы:** подсветка фона
- **Карточки контактов:** подсветка границы

### Keyframe-анимации

- **Hero:** `fadeInUp` для текста, `fadeInScale` для круга, `bounce` для индикатора скролла
- **Кнопка отправки:** `shimmer` — бегущий блик при отправке формы
