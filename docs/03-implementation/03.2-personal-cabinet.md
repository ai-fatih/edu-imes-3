# 3.2 Личный кабинет и CRM

## Общая архитектура авторизации

В демо-версии аутентификация реализована без пароля — по вводу имени и email:

```
/login
├── Вкладка «Клиент» → ввод имени + email → /dashboard?name=...&email=...
└── Вкладка «Сотрудник ПБС» → ввод имени → /employee/dashboard?name=...
```

Данные пользователя передаются через URL-параметры (`useSearchParams`).

## Личный кабинет клиента

**Файл:** `src/pages/Dashboard.jsx`

### Функционал

| Функция | Реализация |
|---------|-----------|
| Приветствие | Имя из URL-параметра |
| Статистика | 3 карточки: всего заказов, в работе, выполнено |
| Список заказов | Аккордеоны с деталями |
| Фильтрация | По email клиента (только свои заказы) |
| История | Комментарии с аватарами (сотрудник/система/клиент) |
| Новый заказ | Кнопка → OrderModal |

### Ключевой код: фильтрация заказов

```jsx
const [params] = useSearchParams()
const name = params.get('name') || 'Клиент'
const email = params.get('email') || ''
const myOrders = orders.filter(o => o.clientEmail === email || (!email && o.clientName === name))
```

## CRM-панель сотрудника

**Файл:** `src/pages/EmployeeDashboard.jsx`

### Функционал

| Функция | Реализация |
|---------|-----------|
| Статистика | 4 карточки: всего, новые, в работе, выполнено |
| Фильтрация | Чипсы по всем статусам (активный подсвечен) |
| Таблица заказов | Все заказы, кликабельные строки |
| Детали заказа | Сайдбар (Drawer) при клике на строку |
| Смена статуса | Select внутри сайдбара |
| Заметки | Textarea + кнопка «Сохранить заметку» |
| Комментарии | TextField + Enter/Send |
| Системные комменты | Авто-добавление при смене статуса |

### Ключевой код: смена статуса + авто-комментарий

```jsx
const updateStatus = (id, status) => dispatch({
  type: 'UPDATE_STATUS',
  payload: { id, status },
})

// В редьюсере:
case 'UPDATE_STATUS':
  return state.map(o => o.id === id ? {
    ...o, status,
    comments: [...o.comments, {
      id: `c${Date.now()}`,
      text: `Статус изменён на «${STATUS_LABELS[status]}»`,
      author: 'system',
      authorName: '',
      createdAt: new Date().toISOString(),
    }]
  } : o)
```

### Компоненты MUI в CRM

- `Drawer` — сайдбар детального просмотра
- `Table`, `TableRow`, `TableCell` — таблица заказов
- `Chip` — фильтры по статусу и отображение статусов
- `TextField` — для заметок и комментариев
- `Select` / `MenuItem` — смена статуса
- `Avatar` — аватарки в комментариях
- `Tooltip` — подсказка для кнопки отправки комментария
