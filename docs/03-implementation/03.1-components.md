# 3.1 Разработка компонентов

## Архитектура компонентов

Приложение построено по принципу **компонентного подхода React**: каждый элемент интерфейса — независимый, переиспользуемый компонент.

```
App
├── Navbar
├── Home
│   ├── Hero
│   ├── Services
│   ├── About
│   ├── Contact
│   └── OrderModal
├── Login
├── Dashboard
├── EmployeeDashboard
└── NotFound
Footer
```

## Структура проекта

```
src/
```

## Ключевые компоненты

### Navbar

**Файл:** `src/components/Navbar.jsx`

Компонент фиксированной навигации с адаптацией под скролл:

- **Scroll-aware:** при скролле >50px меняет фон с прозрачного на белый (blur-эффект), цвет текста — с белого на тёмный
- **Desktop:** inline-кнопки навигации + «Личный кабинет» + «CRM»
- **Mobile:** гамбургер-меню → Drawer с белым текстом на тёмном фоне
- **Anchor-навигация:** поддержка `/#services`, `/#about`, `/#contact` через `scrollIntoView`

```jsx
// Пример: изменение стиля при скролле
const [scrolled, setScrolled] = useState(false)
useEffect(() => {
  const onScroll = () => setScrolled(window.scrollY > 50)
  window.addEventListener('scroll', onScroll, { passive: true })
  return () => window.removeEventListener('scroll', onScroll)
}, [])
```

### Hero

**Файл:** `src/components/Hero.jsx`

Полноэкранный блок с градиентным фоном (`#0d1150 → #1a237e → #283593`), декоративными кругами и анимацией появления (CSS keyframes `fadeInUp`).

- Две CTA-кнопки: «Заказать мероприятие» (открывает OrderModal) и «Наши услуги» (скролл к секции)
- Декоративный элемент «С 2008 года» (круг с радиальным градиентом)
- Индикатор скролла с bounce-анимацией

### Services

**Файл:** `src/components/Services.jsx`

Сетка 3×2 карточек услуг. Каждая карточка содержит иконку в цветном боксе, название и описание.

- **Анимация:** `useInView` с каскадной задержкой `i * 0.1s`
- **Hover:** подъём карточки, усиление тени, подсветка иконки
- **Иконки:** 6 MUI-иконок (Event, Cake, Groups, Business, Chair, RestaurantMenu)

### About

**Файл:** `src/components/About.jsx`

Двухколоночная секция:
- **Левая колонка:** текст о компании, чеклист с `CheckCircleIcon` (золотой цвет)
- **Правая колонка:** 4 стат-карточки (2008, 500+, 98%, 50+) с каскадной анимацией

### Contact

**Файл:** `src/components/Contact.jsx`

Секция обратной связи:
- **Левая колонка:** карточки контактов (телефон, email, адрес) с иконками
- **Правая колонка:** форма с полями имя, телефон, email, сообщение
- **Валидация:** обязательные поля имя и телефон
- **Snackbar:** уведомление об успешной отправке

### OrderModal

**Файл:** `src/components/OrderModal.jsx`

Модальное окно создания заказа с современным UX:

- **Тип мероприятия:** визуальные кнопки-чипсы с иконками и цветами (6 вариантов + «Другое» с текстовым полем)
- **Количество гостей:** Slider с отметками (10, 50, 100, 200, 500) и иконкой `RestaurantIcon`
- **Анимация отправки:** кнопка с shimmer-эффектом и сменой текста на «✓ Отправлено!»
- **Закрытие:** иконка крестика в углу (без кнопки «Отмена»)
- **Валидация:** имя, телефон, тип и дата обязательны

### Footer

**Файл:** `src/components/Footer.jsx`

4-колоночный футер с цветом `#0d1150`: бренд, услуги, контакты, ссылка на ЛК. Год копирайта автоматический.

## Хуки

### useInView

**Файл:** `src/hooks/useInView.js`

Кастомный хук для анимации при скролле. Использует `IntersectionObserver`:

```jsx
const [ref, inView] = useInView({ threshold: 0.15, triggerOnce: true })
```

- `ref` — прикрепить к отслеживаемому элементу
- `inView` — `true`, когда элемент появился в окне просмотра
- `threshold` — порог видимости (0–1)
- `triggerOnce` — сработать только один раз
