# 4.3 Исправление замечаний

В процессе тестирования были выявлены и исправлены следующие замечания.

## Замечание 1: Кнопка «Заказать мероприятие» не реагирует на клик

**Статус:** ✅ Исправлено

**Описание:** На Hero-блоке кнопка «Заказать мероприятие» не имела обработчика `onClick`. При клике ничего не происходило.

**Причина:** В компоненте `Hero.jsx` отсутствовал проп `onClick` для кнопки. Компонент `Home.jsx` не передавал обработчик.

**Решение:**

1. В `Home.jsx` добавлено состояние `orderOpen` и передача `onOrder={() => setOrderOpen(true)}` в Hero.
2. В `Hero.jsx` добавлен `onClick={onOrder}` на кнопку.
3. В `Home.jsx` добавлен компонент `<OrderModal>` с управлением открытия/закрытия.

```jsx
// Home.jsx
const [orderOpen, setOrderOpen] = useState(false)
<Hero onOrder={() => setOrderOpen(true)} />
<OrderModal open={orderOpen} onClose={() => setOrderOpen(false)} />
```

```jsx
// Hero.jsx
<Button onClick={onOrder} ...>
  Заказать мероприятие
</Button>
```

## Замечание 2: Отсутствует страница 404

**Статус:** ✅ Исправлено

**Описание:** При переходе на несуществующий URL отображалась пустая страница. Пользователь не получал обратной связи.

**Причина:** В маршрутизации `App.jsx` отсутствовал catch-all route (`path="*"`).

**Решение:**

1. Создан компонент `NotFound.jsx` с иконкой `SentimentDissatisfiedIcon`, сообщением «Страница не найдена» и кнопкой «На главную».
2. В `App.jsx` добавлен маршрут `<Route path="*" element={<NotFound />} />`.

## Замечание 3: Контактная форма — декоративная, не реагирует

**Статус:** ✅ Исправлено

**Описание:** Поля формы в секции «Контакты» не имели состояния (`value`, `onChange`), а кнопка — обработчика `onSubmit`.

**Причина:** Форма была свёрстана как статическая разметка.

**Решение:**
1. Добавлено React-состояние для полей формы.
2. Добавлены `handleChange` и `handleSubmit`.
3. Валидация обязательных полей (имя, телефон).
4. Snackbar-уведомление при отправке.

## Замечание 4: Navbar перекрывает контент при anchor-ссылках

**Статус:** ✅ Исправлено

**Описание:** При клике на «Услуги», «О нас», «Контакты» верхняя часть секции скрывалась под фиксированным navbar.

**Причина:** Фиксированный navbar (72px) не был учтён при скролле к якорям.

**Решение:** Добавлен `scrollPaddingTop: '80px'` в глобальные стили `MuiCssBaseline` в `theme.js`.

## Замечание 5: Тип мероприятия — неудобный dropdown

**Статус:** ✅ Исправлено (улучшение UX)

**Описание:** В форме заказа тип мероприятия выбирался через стандартный `<select>`. Это неудобно на мобильных и не даёт визуального представления об опциях.

**Решение:** Dropdown заменён на визуальные чипсы-кнопки с иконками и цветами для каждого типа (Свадьба, Корпоратив, День рождения, Бизнес-форум, Кейтеринг, Другое). При выборе «Другое» появляется текстовое поле для ввода.

## Замечание 6: Количество гостей — обычное числовое поле

**Статус:** ✅ Исправлено (улучшение UX)

**Описание:** Поле «Гостей» было простым `<input type="number">`. Пользователь не понимал диапазон значений.

**Решение:** Заменено на MUI `Slider` с иконкой `RestaurantIcon` (вилка + нож). Метки: 10, 50, 100, 200, 500. Отображается текущее значение.

## Замечание 7: Модалка заказа имеет лишнюю кнопку «Отмена»

**Статус:** ✅ Исправлено (улучшение UX)

**Описание:** В модалке были две кнопки закрытия: «Отмена» и крестик. Это избыточно.

**Решение:** Кнопка «Отмена» удалена. Оставлен только крестик в углу (Material UI IconButton). Это соответствует современным практикам UI/UX.
