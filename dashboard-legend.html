Пользовательский путь (User Flow)
1 Клиент заходит на сайт-визитку → видит Hero-блок с предложением
2 Изучает услуги (корпоративы, свадьбы, кейтеринг) → заполняет форму
3 Регистрируется в личном кабинете → отслеживает статус бронирования
4 Получает подтверждение, управляет заказами, связывается с менеджером
Инструменты: Figma (прототип), React Router (навигация), MUI (UI)
Ценность для бизнеса и клиента
Для компании:
  • • Сокращение времени обработки заявки с 2 дней → до 2 часов
  • • Снижение нагрузки на менеджеров (самообслуживание в ЛК)
  • • Рост конверсии посетитель → заявка (+25% за счёт формы на сайте)
  • • Единая база клиентов и истории бронирований
Для клиента:
  • • Подача заявки в один клик без звонков
  • • Прозрачный статус бронирования 24/7
  • • История всех заказов в личном кабинете
KPI:
Конверсия → 25%
Время заявки → -85%
Загрузка стр. → < 2 с
SLA:
Ответ менеджера → 15 мин
Доступность → 99.9%
Uptime (Vercel) → 99.99%
